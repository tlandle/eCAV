# MTR base checkpoint

`best_model.pth` is the pretrained Motion Transformer checkpoint from
the original MTR repository. It is ~4 GB and is not stored in this
repository (exceeds GitHub LFS 2 GB per-file limit).

Download it from the MTR project and place it at
`ecav/ml_manager/models/mtr/best_model.pth` before running any
pipeline that uses MTR prediction.
