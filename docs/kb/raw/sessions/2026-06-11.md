## Key Decisions

- Daemon does NOT persist obstacle state in `_vehicle_state_store` (keyed by managed
  vehicle ID). This is the right separation — state store is for ego lifecycle, not
  for scene observations.
- Fallback export (direct from src when store has no snapshot) prevents the handoff
  from failing if per-tick uploads missed the first few ticks of the scenario.
- `_StateStore` is a `runtime_checkable Protocol` — satisfies both `sim_api.ScenarioManager`
  (Phase 1) and any future gRPC-backed store (Phase 2) without an ABC import.
