### Phase 8 End-to-End Test — Bug Chain

Attempted first full distributed edge run. Fixed a chain of runtime crashes:

**1. "parent actor not found" in orchestrator**
- `GnssSensor`/`ImuSensor` `spawn_actor(attach_to=ego)` called on the orchestrator's proxy VehicleManager
- jrapp hint: bypass this based on the `proxy` attribute (activate=False)
- Fix: `localization_manager.py` guards sensor creation with `if self.activate:`; `vehicle_manager.py` forces `localization.activate = False` for distributed proxy VMs

**2. `ModuleNotFoundError: No module named 'perception_pb2'` in RSU container**
- `ecloud_actor_client.py` and `distributed_actor_client.py` missing `ecav/protos` in sys.path
- Fix: `sys.path.insert(0, os.path.join(os.getcwd(), 'ecav', 'protos'))` added to both

**3. `AttributeError: EcloudConfig has no attribute 'fatal_errors'`**
- Referenced in exception handlers, never defined on class
- Fix: added `fatal_errors = True` class attribute to `EcloudConfig`

**4. `push_q.empty()` assert — root cause: timing race**
- Tick arrived before actor finished `run()` initialization
- jrapp clarification: push_q is intentionally a single-slot channel; assert must stay (enforces "queue of 1" invariant)
- Root cause: no gate between actor initialization completion and tick loop start

### Edge Actor-Ready Handshake (new protocol)

Designed and fully implemented a 10-step initialization barrier. The key insight: `run_comms()` must not return until all actors confirm readiness.

**New RPCs:**
- `Edge_ActorReady(RegistrationInfo) → Empty` (actor → edge)
- `Edge_ActorsReady(EdgeReadyNotification) → Empty` (edge → orchestrator)
- New message: `EdgeReadyNotification { edge_index, num_actors }`

**Push_q ordering after fix:**

| Event | push_q source | consumed by |
|-------|--------------|-------------|
| All edges `Edge_Register` | C++ `Edge_Register` handler | `server_start_scenario` push_q.get #1 |
| All edges `Edge_ActorsReady` | C++ `Edge_ActorsReady` handler | `run_comms()` push_q.get #2 |
| All edges `Edge_TickComplete` per tick | C++ `Edge_TickComplete` handler | `server_do_tick` push_q.get |

**Also eliminated:** "duplicate tick_id:-1" push. `send_carla_data_to_ecav()` in edge mode now calls `Edge_ActorReady` on the edge instead of `Client_RegisterVehicle` on the orchestrator.
