## Key Decisions

- `sample_ms()` public method on `LatencyModel` rather than calling `_sample_ms()`
  cross-module. Correct abstraction; one-line addition.
- Serialization cost is modeled from `payload.payload_bytes() * rate_ms_per_byte`
  (default 1e-5 ≈ 100 MB/s). Never from `perf_counter` around real pickle — that
  would conflate simulator-host performance with the simulated measurement.
- `total_ms = serialize + network + serialize` (symmetric: same rate both ends).
- Plan file showed Step 0 base/pluggable items as unchecked, but all four methods
  (`export_vehicle_state`, `import_vehicle_state`, `relinquish`, `accept`) were already
  committed to both `_BaseEdgeManager` and `_PluggableEdgeBase`. Checklist updated.
