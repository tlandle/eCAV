### WF_GRPC_ENDPOINT Fix
`-l -d` hit `localhost:18000` (HTTP) instead of `localhost:18002` (gRPC) because `CavWorld(config=None)` in the container gives ml_manager an empty config dict, so `worldfusion_grpc_endpoint` defaults to `None` and the gRPC path is skipped.

Fix: `start_actors.sh` passes `-e WF_GRPC_ENDPOINT=localhost:18002` to ego and RSU containers when `-l` active. First-checked path in worldfusion_perception_manager.py, bypasses ml_manager lookup entirely.

Late fusion confirmed unaffected — `yolo_endpoint` already has a concrete default (`localhost:18001`).
