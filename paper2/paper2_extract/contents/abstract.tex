Edge-hosted cooperative world models that fuse intermediate features from
multiple connected autonomous vehicles (CAVs) enable perception beyond
line-of-sight. However, as the number of participating agents grows, the
full edge pipeline (spatial-attention fusion, multi-object tracking,
transformer trajectory prediction) encounters a steep deadline cliff:
on a commodity GPU the static pipeline exceeds a 100\,ms planner
deadline at roughly $N=10$ agents, and latency grows super-linearly
thereafter.  We present a deadline-aware adaptive controller with two
decision variables.  An input contribution filter selects the $K$ most
informative agents per tick using conflict-zone scoring. A risk-budgeted
scheduler allocates the residual compute budget to the subset of tracked
objects whose cached predictions have diverged, prioritized by a
continuous risk score combining speed, proximity, occlusion, and
conflict geometry.  Temporal amortization gates fresh neural-network
inference to divergent objects only, reusing cached predictions for
stable tracks.  Evaluated offline on real post-backbone features across
$N \in \{4, 8, 16, 24, 32, 48, 64\}$ agents, the adaptive controller
maintains 100\% deadline compliance while the static baseline fails at
$N \geq 16$.  Risk-stratified quality metrics confirm that prediction
accuracy for safety-critical objects is preserved under adaptation.
