\section{Conclusion}
\label{sec:conclusion}

We characterize the deadline cliff that emerges when a cooperative
world-model pipeline (WorldFusion attention fusion, AB3DMOT tracking,
MTR transformer prediction) is deployed on an edge server at dense
scale.  On commodity hardware, the static pipeline exceeds the 100\,ms
planner deadline at $N \approx 10$ agents; at $N{=}64$ it reaches
184\,ms.

Our adaptive controller selects the number of contributing agents
(input filter $K$) and the set of objects receiving fresh prediction
(risk-budgeted $\mathbf{x}$) to maximize risk-weighted utility within
the deadline budget.  Three mechanisms interact: input contribution
filtering bounds fusion cost, temporal amortization reuses cached
predictions for stable tracks, and risk-budgeted scheduling
prioritizes the objects most relevant to planner safety.

In a five-way offline ablation across $N \in \{4, \ldots, 64\}$,
the combined controller is the only configuration achieving 100\%
deadline compliance at every scale, while maintaining prediction
quality for high-risk objects.  Ongoing work extends this evaluation
to Multi-V2X (up to 31 real CAVs per frame) and closed-loop CARLA
simulation to validate the safety argument end-to-end.
